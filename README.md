A one-sentence entry for the [make.fun](https://make.fun/bounty/u-suroso-69-one-sentence-absurd-invention-pitch-5326c34a) bounty "One-Sentence Absurd Invention Pitch" — pitching a ridiculous invention that fixes a tiny everyday annoyance, in a single sentence.

## Run

```sh
python3 main.py
```

The program reads `entry.txt` next to it and writes the exact bytes to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output` when unset).
